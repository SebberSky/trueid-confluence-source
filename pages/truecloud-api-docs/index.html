Using True Cloud APIs

All customer APIs (except shared-object login) require an access token. Endpoints are labeled by caller layer:

  • Native REST — called directly via NetworkingProvider<TrueCloudAPI>. Paths under /v1/....
  • AWS S3 SDK — binary upload/download via AWSS3TransferUtility. Not True Cloud REST paths.

No True Cloud REST endpoint is invoked through an SDK. The AWS SDK talks to S3 after native STS.

Domain / Servers

Resolved by DomainNameManager: Firestore → Documents cache → bundled ConfigDomain.json.
