คลังหน้า HTML สำหรับฝังบน Confluence

เพิ่มไฟล์ใน pages/<slug>/index.html แล้วลงทะเบียนใน manifest.json — กดคัดลอก iframe ไปวางใน HTML macro / iframe macro บน Confluence

วิธีฝังบน Confluence

  1. เปิดหน้าจากรายการด้านบน → กด คัดลอก iframe
  2. บน Confluence: Insert → HTML macro (หรือ Iframe macro ถ้ามี) แล้ววางโค้ด
  3. ถ้าขึ้น “refused to connect” แปลว่าโฮสต์บล็อก frame — ใช้ Cloudflare Pages / Netlify จาก repo นี้ (มี _headers ให้อยู่แล้ว)
